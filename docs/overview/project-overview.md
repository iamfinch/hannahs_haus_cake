## What is Hannah's Haus Cake?

Hannah's Haus Cake is a web-based system that helps manage the process of adopting dogs. Think of it as a digital assistant that handles everything from when someone expresses interest in a dog, through the application and approval process, all the way to completing the adoption.

**Purpose:** Make dog adoptions organized, efficient, and transparent for both adopters and administrators.

---

## Who Uses This System?

###  🐕 **Dog Adopters** (Regular Users)
People interested in adopting a dog:
- Browse available dogs
- Create a profile with their information

### 👨‍💼 **Administrators** (Staff)
Hannah's Haus staff members:

## Key Features

### 1. **Secure User Accounts**

**What it does:** Keeps each person's information private and secure.

- Users create accounts with email and password
- Passwords are encrypted for security
- Each person can only see and edit their own information
- Administrators have special access to manage applications

**Why it matters:** Protects personal information and ensures only authorized people can approve adoptions.

---

### 2. **Dog Listings**

**What it does:** Shows all dogs available for adoption.

- Browse through available dogs
- See photos and descriptions
- View dog details (age, breed, personality)
- Filter to see only available dogs (not already adopted)

**Why it matters:** Helps potential adopters find the right dog for their family.

---

### 3. **Adoption Application Process**

**What it does:** Guides adopters through submitting an application.

**The Journey:**
1. **User finds a dog they like** and clicks "Apply for Adoption"
2. **User fills out application form** with:
   - Housing information (house type, address)
   - Family details (children, other pets)
   - Pet ownership history
   - Preferred pickup method

3. **Application is submitted** and user receives confirmation email
4. **Admin team receives notification** to review the application
5. **Admin reviews and makes decision** (approve or decline)
6. **User receives notification** of the decision via email

**Application Statuses:**
- **Pending** - Waiting for admin review (yellow status)
- **Approved** - Application accepted (green status)
- **Declined** - Application not accepted (gray status)

**Why it matters:** Creates a clear, organized process that doesn't rely on email chains or manual tracking.

---

### 4. **Admin Dashboard**

**What it does:** Gives staff a central place to manage all applications.

**Features:**
- See all pending applications at a glance
- View applicant details and qualifications
- Approve or decline applications with one click
- See statistics (total pending, approved, declined)
- Automatic handling of competing applications

**Smart Features:**
- When one application is approved, competing applications for the same dog are automatically declined
- Dog is automatically marked as adopted
- All affected users receive appropriate email notifications

**Why it matters:** Saves time and prevents errors by automating routine tasks.

---

### 5. **Automated Email Notifications**

**What it does:** Keeps everyone informed automatically.

**Email Types:**

**For Adopters:**
- **Application Received** - Confirms application was submitted successfully
- **Application Approved** - Celebratory email with next steps for adoption
- **Application Declined** - Empathetic message encouraging them to apply for other dogs

**For Administrators:**
- **New Application Alert** - Notifies staff when applications need review

**Email Features:**
- Professional, friendly design
- Clear next steps
- Automatic sending (no manual work needed)
- Works on all email programs and phones

**Why it matters:** Reduces administrative workload and ensures timely communication.

## Common Questions

### Q: Can I apply for multiple dogs?

Yes! You can submit applications for different dogs. However, you can only have one pending application per dog at a time.

### Q: How long does the review process take?

Applications are typically reviewed within 2-3 business days. You'll receive an email as soon as a decision is made.

### Q: What happens if my application is declined?

You'll receive an empathetic email explaining that this particular match wasn't ideal, but encouraging you to apply for other dogs that might be a better fit. There's no limit to how many times you can apply.

### Q: Can I edit my application after submitting?

Currently, applications cannot be edited after submission. If you need to make changes, please contact the Hannah's Haus team directly.

### Q: Do I need to check the website for updates?

No! You'll receive email notifications automatically when there are updates to your application. However, you can always log in to check your application status.

### Q: Can administrators see all my information?

Administrators can see the information you provided in your adoption application (housing, family details, pet history). This is necessary to make informed approval decisions. Your password and other sensitive information are encrypted and protected.

## Glossary (Key Terms Explained)

**Application:** A formal request to adopt a specific dog, submitted through the website.

**Admin/Administrator:** A staff member with special access to review and approve applications.

**Dashboard:** The admin's main screen showing all pending applications and statistics.

**Pending:** An application that's waiting to be reviewed (hasn't been approved or declined yet).

**Approved:** An application that's been accepted - the adopter can proceed with adoption.

**Declined:** An application that wasn't approved for this particular dog.

**Status:** The current state of an application (pending, approved, or declined).

**Profile:** Your personal account information and preferences.

**Email Notification:** An automatic email sent when something important happens (application submitted, decision made, etc.).
